# AuroMix Studio

Interactive gold-alloy concept lab for jewelry teams.

## Included
- Gold, silver, copper, palladium, zinc and balance controls
- Karat/fineness conversion
- Live color/surface preview
- Directional strength, wear and casting/detail indicators
- Local combination suggestion engine
- JSON report export
- Dependency-free GitHub Pages frontend

## Modeling boundary
This is a design-screening simulator, not a certified metallurgical model. Actual hardness, tensile behavior, color, fluidity, porosity, phase behavior and finish depend on exact chemistry, processing, heat treatment, microstructure and production controls. Use the recipes as exploration starting points and validate production formulas in a controlled lab.

## Commercial path
The project is ready to be extended into a paid/private jewelry R&D platform with measured datasets, saved experiments, organization accounts, batch/BOM tracking, supplier catalogs, calibrated models and an API-powered formulation assistant.
