# AuroMix Studio — Sales Brief

## Product
AuroMix Studio is a browser-based jewelry alloy concept lab that helps designers and jewelry teams explore composition, appearance and directional strength indicators before physical testing.

## Suggested commercial packaging
- Starter source: USD 149–499
- Branded/private edition: USD 750–2,500
- Calibrated lab edition: custom quote
- SaaS edition: subscription + setup

## Upsell features
- Measured alloy database
- Customer-specific recipe libraries
- Saved experiments and team workspaces
- Supplier and batch tracking
- BOM / purchase sheet export
- Lab test result capture
- Calibrated color/hardness/casting models
- Private AI formulation assistant

The current engine is intentionally transparent and heuristic. Commercial production use should add validated experimental data and laboratory QA controls.
